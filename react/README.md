## Hook
### State Hooks
useState: Stores state values in a functional component.
useReducer: Manages complex state logic using a reducer function.
### Context Hooks
useContext: Reads and subscribes to a React context.
### Ref Hooks
useRef: Holds a mutable reference value that does not trigger re-renders.
useImperativeHandle: Customizes the instance value exposed to parent components when using a ref.
### Effect Hooks
useEffect: Connects a component to an external system (side effects).
useLayoutEffect: Fires synchronously after all DOM mutations but before browser paint.
useInsertionEffect: Fires before DOM mutations to inject dynamic styles.
### Perforzmance Hooks
useMemo: Caches the calculated result of an expensive computation.
useCallback: Caches a function definition between component re-renders.
useTransition: Updates state without blocking the user interface.useDeferredValue: Defers updating a non-critical part of the user interface.
### Resource Hooks
use: Reads the value of a resource like a Promise or a Context.
### OtherHooks
useId: Generates unique IDs to pass to accessibility attributes.
useSyncExternalStore: Subscribes to an external data store.
useDebugValue: Adds a custom label to a hook in React DevTools.
